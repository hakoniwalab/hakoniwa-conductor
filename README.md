# Hakoniwa Conductor / 箱庭コンダクタ

箱庭コンダクタの公開リポジトリです。

本リポジトリでは、学術研究・教育・非商用研究開発および論文の再現性検証に利用できる**無償版バイナリ**を公開します。無償版ではソースコードは公開しません。

商用利用向けには、別途「箱庭コンダクタPRO」を提供します。箱庭コンダクタPROでは、契約条件に基づきソースコード、ドキュメント、バイナリーファイルを含むコンテンツを提供します。

> 現在、このリポジトリは公開準備中です。最初の段階として、ライセンス体系を定義しています。

### 無償版について

無償版は**バイナリ配布のみ**です。本ライセンスの下ではソースコードは提供されません。

無償版は、学術論文の査読、追試、再現性検証およびベンチマークを含む非商用目的で利用できます。研究結果、計測結果、ベンチマーク結果、図表および論文の公表も可能です。

バイナリのリバースエンジニアリング、逆コンパイル、逆アセンブル、改変および派生物の作成は禁止されています。

### 商用版について

商用利用には、合同会社箱庭ラボとの間で「箱庭コンダクタPRO」の商用ライセンス契約を締結する必要があります。

PROライセンスでは、本ソフトウェアを閲覧、インストール、改変、コンパイルし、契約対象のユーザープロジェクトにおいて商品やサービス、部門内部利用等に組み込んで使用する権利を定めています。
