# Hakoniwa Conductor 機能実現範囲

[English](feature-scope.md)

本書では、設計上の概念に対してHakoniwa Conductorが提供する機能範囲を示します。概念の規範的な定義は `hakoniwa-design-docs` を参照してください。

| 機能 | 状態 | 補足 |
| --- | --- | --- |
| 分散時刻同期 | 対応 | 設計条件内で有界ドリフトを扱う |
| シミュレーション開始・停止・リセット | 対応 | Business Pack Recipeから操作する |
| EUのOwner管理 | 対応 | Ownerの一意性を管理する |
| Epoch管理 | 対応 | 実行責任の世代を識別する |
| Commit Point | 対応 | 責任と因果境界の意味論的確定点 |
| Runtime Delegation | 対応 | 実行中にEUのOwnerを切り替える |
| 時刻同期誤差の計測・データ出力 | 未対応 | 基準時刻と観測時刻の差を数値データとして取得する機能は提供していない |

## 状態の表記

- **対応**: 現在利用でき、検証済み
- **試験対応**: 利用可能だが明記すべき制約がある
- **計画**: ロードマップ上の対象だが未提供
- **対象外**: 製品の目的として扱わない
- **未対応**: 現時点では提供していない

ここでいうデータ出力は、時刻同期のズレ幅を評価できる数値データの契約を指します。現時点では、このデータ出力もUIやグラフによる可視化も提供していません。
