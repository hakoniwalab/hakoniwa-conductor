# Hakoniwa Conductor v1.0.0

[English](v1.0.0.md)

## 配布物

```text
hakoniwa-conductor-v1.0.0-linux-x86_64.zip
hakoniwa-conductor-v1.0.0-linux-x86_64.zip.sha256
hakoniwa-conductor-v1.0.0-macos-arm64.zip
hakoniwa-conductor-v1.0.0-macos-arm64.zip.sha256
```

対象環境はUbuntu 24.04 x86_64とmacOS arm64です。Linux ZIPはDocker `linux/amd64`で生成します。両ZIPともConductor固有バイナリ、公開Generator、利用文書、ライセンス、ビルド契約のメタデータを収録します。

## 既知の制約

- Foundation共有ライブラリはZIPに重複同梱しません。
- Business PackのConductor Recipe、ユーザー設定スキーマ、公開サンプル設定は後続提供です。v1.0.0 ZIP単体ではサンプル構成を起動できません。
- 時刻同期誤差を評価するための数値データ出力、およびUIやグラフによる可視化は提供していません。
