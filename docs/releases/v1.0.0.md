# Hakoniwa Conductor v1.0.0

[日本語](v1.0.0-ja.md)

## Artifacts

```text
hakoniwa-conductor-v1.0.0-linux-x86_64.zip
hakoniwa-conductor-v1.0.0-linux-x86_64.zip.sha256
hakoniwa-conductor-v1.0.0-macos-arm64.zip
hakoniwa-conductor-v1.0.0-macos-arm64.zip.sha256
```

The targets are Ubuntu 24.04 x86-64 and macOS arm64. Docker builds the Linux archive for `linux/amd64`. Both archives contain Conductor-specific binaries, public generators, user documentation, licenses, and build-contract metadata.

## Known limitations

- Foundation shared libraries are not duplicated in the ZIP.
- The Business Pack Conductor Recipe, user configuration schema, and public sample configuration are follow-up deliverables. The v1.0.0 ZIP alone cannot start a sample topology.
- Numeric data output for evaluating time-synchronization error, and UI or graph visualization, are not provided.
