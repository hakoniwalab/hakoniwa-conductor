# Hakoniwa Conductor v1.1.0

[English](v1.1.0.md)

## 配布物

```text
hakoniwa-conductor-v1.1.0-linux-x86_64.zip
hakoniwa-conductor-v1.1.0-linux-x86_64.zip.sha256
hakoniwa-conductor-v1.1.0-macos-arm64.zip
hakoniwa-conductor-v1.1.0-macos-arm64.zip.sha256
```

対象環境はUbuntu 24.04 x86_64とmacOS arm64です。Linux ZIPは、WSL2を含む
Ubuntu 24.04 x86_64環境でnative buildします。

## 主な変更

- Server / Clientのrun loop pacingとして`real_sleep_msec >= 0`を設定でき、`0`で明示的なsleepを無効化できます。
- `simtime_publish_mode`に`immediate`と`delta_boundary`を追加しました。
- `simtime_publish_interval_usec`を`delta_time_usec`から独立して設定できます。
- Server / Clientの双方で同じSimTime publish policyを適用します。
- `hako.py configure`がtiming fieldを生成設定へ伝播し、生成後のeffective configを検証します。
- time-sync起動前にclient joinを待つreadiness contractを追加しました。

これらの設定は互いに独立しています。`delta_time_usec`はConductorの内部時刻進行、
`simtime_publish_interval_usec`はnode間の仮想時刻通知周期、`real_sleep_msec`はrun loopの
壁時計待機を制御します。

## Foundation契約

各パッケージは、Hakoniwa Business Packが管理するFoundationを使用してbuildします。
Foundation componentのrevisionはリリース全体で一つに固定せず、OSごとのbuildで実際に
使用したCore、Endpoint、RPC、Bridgeのrevisionを、成果物内の
`metadata/build-contract.txt`へ記録します。同ファイルには、Hakoniwa Conductor PROの
source revisionと、使用したhakoniwa-pdu Python package versionも記録します。
v1.1.0のhakoniwa-pdu Python package versionは`1.6.9`です。

## 互換性

既存設定で新しいfieldを省略した場合は、従来の`immediate`動作と
`simtime_publish_interval_usec = delta_time_usec`を維持します。

Foundation共有ライブラリはZIPへ同梱しません。対応するHakoniwa Business Pack Recipeで
Foundationを準備し、ZIP内の`VERSION`と`metadata/build-contract.txt`を検証してください。
