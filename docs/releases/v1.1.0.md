is built natively on Ubuntu 24.04 x86-64, including Ubuntu under WSL2.

## Highlights

- Server and client run-loop pacing accepts `real_sleep_msec >= 0`; `0` explicitly disables sleeping.
- `simtime_publish_mode` supports `immediate` and `delta_boundary`.
- `simtime_publish_interval_usec` can be configured independently of `delta_time_usec`.
- The same SimTime publication policy is applied by both server and client.
- `hako.py configure` propagates timing fields and validates the generated effective configuration.
- The time-sync startup path waits for client join readiness before starting the simulation.

These controls are independent: `delta_time_usec` controls Conductor internal
time progression, `simtime_publish_interval_usec` controls inter-node virtual
time publication cadence, and `real_sleep_msec` controls run-loop wall-clock
pacing.

## Foundation contract

Each package is built against the Foundation managed by Hakoniwa Business Pack.
Foundation component revisions are not forced to one release-wide set. Instead,
`metadata/build-contract.txt` in each artifact records the Core, Endpoint, RPC,
and Bridge revisions actually used for that platform build. The same file also
records the Hakoniwa Conductor PRO source revision and the hakoniwa-pdu Python
package version used to create the package.
The hakoniwa-pdu Python package version for v1.1.0 is `1.6.9`.

## Compatibility

When the new fields are omitted, existing configurations retain the previous
`immediate` behavior and `simtime_publish_interval_usec = delta_time_usec`.

Foundation shared libraries are not bundled. Prepare the Foundation through
the corresponding Hakoniwa Business Pack Recipe and verify the package
`VERSION` and `metadata/build-contract.txt`.
